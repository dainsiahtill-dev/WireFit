# WireFit 本地可视化工作台

工作台在本机 Node 24 上运行，浏览器直接连接 `127.0.0.1`。页面使用本地 HTML、CSS、JavaScript 和 SVG，无需云服务、API Key 或前端构建服务。

## 启动与停止

```powershell
cd E:\wirefit
.\wirefit-web.cmd
# 也可使用 .\wirefit.cmd web 或 npm run web
```

打开 <http://127.0.0.1:4318>。前台窗口按 Ctrl-C 停止；后台运行时：

```powershell
.\wirefit-web.cmd --stop
# 自定义端口：启动与停止均指定相同端口
.\wirefit-web.cmd --port 4319
.\wirefit-web.cmd --port 4319 --stop
```

首次迁移或更新 TypeScript 后先运行 `npm ci --ignore-scripts`、`npm run build`。Windows 启动器优先使用项目内 `.tools/runtime` 的 Node 24；其他系统使用已安装的 Node 24。`--stop` 验证本服务实例身份后请求正常关闭，等待所属任务清理，不按端口直接终止其他进程。

## 工作台页面

| 页面 | 可用操作与来源 |
| --- | --- |
| 研究总览 | vmde 目标身份、904 条原生网格核观测、31 例节点 CPU 回放、26 次标签 CPU 调用、未解决问题与证据索引；管理案例显示模型和任务概况 |
| 代码与模型 | 选择六个研究函数，浏览冻结 listing、局部调用图、候选源码和原始证据；图最多 32 个节点、32 条边，截断时明确说明 |
| 运行时间线 | 按独立运行/PID 查看事件，筛选 API、断点、异常和模块，搜索、翻页；展开寄存器、栈、代码及登记的内存快照 |
| 模型实验室 | 选择真实模型，编辑类型化输入和 FP32 参数预览，计算节点与输出，绘制输入扫描曲线；读取实际 Handwired 拟合日志、损失曲线和分组结果 |
| 验证与比较 | 逐项查询原生/CPU 记录，按匹配、失败等状态筛选和翻页；查看输入、保留的原始/候选输出、比较规则及证据 |
| 任务中心 | 新建案例、导入显式模型 JSON；提交真实拟合、Z3 简化、保留集验证和模型比较；轮询、取消本会话任务、查看结果、导出报告及下载文件；使用已安装配置执行 PE 检查、原生观测或解包 |
| IDA 分析 | 使用本机 IDA 9.3 MCP 查询反汇编、伪代码、CFG、交叉引用、字节与类型；独立任务、来源身份、取消、原始证据和报告导出，见 [IDA MCP 文档](IDA-MCP.md) |

没有保存的候选输出会明确显示缺失，不以原始输出补造。CPU 回放、样例夹具、模型证明和原生观测分别标注；任务完成不代表目标完整还原。实验室修改参数属于计算预览，不会改写已保存模型。

## 案例与文件

- 默认 `vmde 研究归档` 为只读证据视图。
- `工作台实验区` 保存在 `.local/workbench/case`，首次启动导入五个真实模型和期望夹具数据集。
- 界面新建案例保存在 `.local/workbench/cases/`，重启后仍可选择。
- `cases/` 和 `artifacts/research/vmde/` 中发现的历史案例只读。查看或误提交任务不会触发历史任务恢复或改写收据。
- 模型、任务和运行列表最多显示 512 项，数据集/Oracle 列表最多 256 项；发生截断会显示实际总数和已展示数。
- 报告写入 `exports/workbench/` 的独立目录。只下载当前服务登记并核验身份的导出文件；重启后可重新导出。

任务中心选择只读案例时，写入操作会清楚提示并使用工作台实验区；可先新建案例以独立保存实验。只有本服务会话提交的任务显示取消能力，历史任务保留其原始状态。

本机文件任务使用固定配置：`pe-static` 为纯静态 PE 检查；DIE、Frida 与 Unlicense 读取已有 `.local` 配置并显示安装状态。动态观测和解包会执行用户指定的本机目标，普通查看研究页面不会执行 vmde。浏览器不接受任意后端命令或工具参数。

## 接口与运行边界

HTTP 服务仅绑定 `127.0.0.1`，校验 Host/Origin；变更请求需要同源页面取得的会话令牌，JSON 请求最多 1 MiB。静态资源和证据读取拒绝符号链接/目录联接及路径穿越。证据通过登记 ID 查询，工件按 SHA-256 读取；浏览器以文本呈现未知内容。

后端分为 `src/web/server.ts`（HTTP）、`workspace.ts`（案例）、`actions.ts`（既有服务适配）、`lab.ts`（既有模型解释器）和 `research*.ts`（只读证据）。前端在 `apps/web/public/`；新增页面可复用请求、取消、错误状态和证据组件。现有 CLI/MCP、Handwired 训练器、Z3 和任务管理器继续承担实际计算。

## 验证

```powershell
npm run build
npm run test:web
npm test
npm run test:e2e
```

浏览器测试使用本机 Microsoft Edge，在独立端口 4329 启动服务，结束后正常关闭。测试会新建带时间戳的验收案例、执行真实 Handwired/Z3 和原文件的纯静态检查，并保留报告；不运行原 vmde、不触发动态解包。其他环境需安装 Edge，或调整 `playwright.config.mjs` 的浏览器配置。

机器可读结果与截图位于 `artifacts/web-workbench/`。浏览器覆盖六页、类型化求值、参数预览、真实拟合/简化、导入、取消、导出、文本注入防护和 390px 移动布局。

当前工作台让已有研究能力可操作、可追溯。完整 vmde 可运行重建、自然图像到矢量输出、VM 语义和真实 OEP 仍未完成；详见 [还原进度](VMDE-RESTORATION.md)。
